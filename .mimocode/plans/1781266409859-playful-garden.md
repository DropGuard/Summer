# Runtime Jandex 自动发现 — 条件装配修复方案

## 决定

1. `@ConfigurationProperties` 不加 `@Component` 元注解，auto-discovery 中特殊处理
2. 自动注册所有接口 + 修复 `@Replaces` 的接口清理
3. `@Replaces` 保持当前分离：类级别在 `discoverBeans()`，方法级别在 `BeanMethodResolver`，`RuntimeConditionResolver` 只做 `@ConditionalOnBean` + 接口清理

## build() 最终流程

```
1. registry.registerSingleton(RuntimeDiMarker)
2. ConfigBinder.setDefaultValueResolver(RuntimeDefaultValueResolver)
3. discoverBeans(index, registry)
   ├─ Jandex 扫描（递归元注解）
   ├─ @ConfigurationProperties → ConfigBinder.bind()
   ├─ topological sort @Component
   ├─ 类级别 @Replaces → 移除被替换的 config
   ├─ @ConditionalOnBean 预检查（config 类）
   ├─ 构造函数依赖检查（constructorDepsSatisfied）
   ├─ 实例化 + 注册（含接口自动注册）
   └─ BeanMethodResolver.resolve()（含方法级别 @Replaces）
4. extraComponents
5. validateRegistry
6. RuntimeConditionResolver.resolve() → @ConditionalOnBean + 接口清理
7. createAopProxies
8. BeanContainer.create()
```
